# Plan 6.2: UI Rework — Plovoucí macOS dok (Floating Dock)

## Objective
Kompletní transformace celošířkového Taskbaru na elegantní plovoucí dok (macOS-style Dock) centrovaný uprostřed dolní části obrazovky. Zjednodušení rozhraní odstraněním přepínače virtuálních ploch (Workspaces) a přidání živých vizuálních indikátorů pro sledování běžících aplikací a jejich stavů (focus, minimalizace).

  <files>src/shell/Taskbar/Taskbar.tsx</files>
  <action>
    Upravte soubor Taskbar.tsx následovně:
    1. Úplně odstraňte import a volání komponenty `WorkspaceSwitcher`.
    2. Předělejte strukturu tak, aby odpovídala sjednocenému doku:
       - Uprostřed doku bude zobrazen seznam běžících oken z `useWindowStore`.
       - U každého tlačítka okna se zobrazí pouze ikona (`win.icon`) — text/title okna schovejte (případně ho zobrazte pouze při hoveru jako popup tooltip pro maximální čistotu docku).
       - Zjistěte, zda je okno aktivní (má focus) a zda je minimalizované, a předejte tyto stavy jako dynamické CSS třídy (`.is-active`, `.is-minimized`, `.has-focus`).
       - Na pravou stranu doku přidejte oddělovač (svislou čáru) a za něj umístěte hodiny (`TaskbarClock`) a uživatelské menu (`TaskbarUserMenu`).
  </action>
  <verify>npx tsc --noEmit</verify>
  <done>Komponenta WorkspaceSwitcher je odstraněna, a struktura Taskbaru je sjednocena do kompaktního řádku ikon oken a systémových widgetů.</done>

<task type="auto">
  <name>Aplikace plovoucích Dock stylů v Taskbar.css</name>
  <files>src/shell/Taskbar/Taskbar.css</files>
  <action>
    Přepište styly v Taskbar.css pro vytvoření macOS Dock efektu:
    1. Změňte `.os-taskbar` na plovoucí element: `position: absolute; bottom: 16px; left: 50%; transform: translateX(-50%); width: auto; max-width: 90vw; height: 60px; padding: 0 16px; border-radius: 20px; border: 1px solid var(--border-default);`.
    2. Použijte silný glassmorphic styl: `background: var(--bg-glass); backdrop-filter: blur(24px); -webkit-backdrop-filter: blur(24px); box-shadow: var(--shadow-lg), 0 0 15px var(--border-glow);`.
    3. Nastylyjte ikony běžících oken: kulaté nebo zaoblené kachličky o rozměru cca 44x44px. Při najetí myší přidejte plynulé zvětšení (scale transition `transform: scale(1.15)`).
    4. Implementujte vizuální indikátory běžících procesů:
       - Pod každou ikonou aplikace vytvořte malou tečku (`::after` pseudo-element).
       - Pokud je aplikace spuštěná na pozadí, tečka má matnou barvu (`background: rgba(255,255,255,0.4)`).
       - Pokud má aplikace aktivní okno (focus), tečka se rozsvítí jasně fialově/modře s drobným stínem (`background: var(--accent-primary); box-shadow: 0 0 6px var(--accent-primary)`).
       - Pokud je aplikace minimalizovaná, ikona získá průhlednost (`opacity: 0.55`).
    5. Nastylyjte oddělovací svislou čáru mezi ikonami a systémovými prvky (Clock/UserMenu).
  </action>
  <verify>npm run build</verify>
  <done>Taskbar je nastylován jako plovoucí zaoblený Dock centrovaný dole, a indikátory (tečky pod ikonami, minimalizace) se chovají správně.</done>
</task>
